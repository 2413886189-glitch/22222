# Java 文件存放目录

## 贪吃蛇小游戏 (`SnakeGame.java`)

基于 GitHub 经典 Java Swing 贪吃蛇实现改进的零依赖单文件版本（兼容 JDK 8+）。

### 主要改进点
- **输入缓冲队列（FIFO）**：最多缓冲 2 步方向输入，彻底解决快速连续按键导致的误撞自身或吞键问题。
- **确定性食物生成**：遍历空位列表随机生成，避免后期蛇身变长后 `while(true)` 随机重试卡顿，满屏时触发通关胜利。
- **精确追尾碰撞判定**：本帧蛇身不增长时允许蛇头紧贴进入当前蛇尾位置。
- **限时金色奖励果**：每吃 5 个普通食物刷新一个限时奖励果（+30 分，顶部显示倒计时进度条）。
- **难度与模式切换**：支持 `1 / 2 / 3` 切换简单/普通/困难难度、`M` 切换经典撞墙/穿墙模式，并随得分平滑加速。
- **最高分持久化**：使用 `java.util.prefs.Preferences` 自动保存历史最高分。

### 编译与运行
```bash
cd java
javac -encoding UTF-8 SnakeGame.java
java SnakeGame
```

### 操作说明
- `↑ ↓ ← →` 或 `W A S D`：控制方向
- `空格` / `P`：开始 / 暂停 / 继续
- `R` / `Enter`：重新开始
- `1` / `2` / `3`：切换难度（非游戏中）
- `M`：切换穿墙 / 撞墙模式（非游戏中）
